# Gleo 0.4.0 beta

Lumen has a new name: **Gleo** (said "GLAY-oh", an old English word for music and joy). This beta is for Windows and Android, in plain words.

## The new name, and what moves over

- **Windows:** Gleo installs beside Lumen. On its first start, Gleo copies your Lumen library, playlists, play counts, settings and cover picks to its own folder (`%APPDATA%\Utkarsh Tripathi\Gleo`). Lumen's folder is kept, so nothing is lost. Once Gleo looks right, uninstall Lumen yourself. The portable version keeps using its `userdata` folder.
- **Android:** Gleo is a new app with a new ID, so it can't update the Lumen test app. **Uninstall Lumen first**, then install Gleo. The Lumen test app had no backup, so Gleo on the phone starts fresh: it reads your Music folder again, and your playlists and play counts start over. From now on, *Settings → Data and updates → Back up* keeps them in one file.
- A new logo: a gold **g** on midnight, and a gold accent instead of coral. The dark theme now has a midnight tint with clearer layers.

## New features

- **Crossfade** (Sound → Playback; off by default). Songs blend by 1 to 12 seconds. Albums that play gaplessly are never crossfaded, and skipping a song cuts straight away.
- **CUE sheets.** One big file plus its `.cue` shows as separate songs. The badge says "· CUE". On Android 11 and newer, add the folder once with *Settings → Library folders → Add folder* (Android lets Gleo read `.cue` files only in a folder picked there).
- **Trim silence** at the start and end of songs (off by default; only gaps of over a second).
- **Remember the position in long files** (over 20 minutes), with "Resumed at … · Start over".
- **Back up & restore in one file** (`.gleobackup`): playlists, play counts, ratings, settings and cover picks. It works between Windows and Android: songs are matched by their path, or else by artist, title and length. A summary shows before anything is restored.
- **Star ratings.** Rate from the song menu (*Rate ▸*), in Now Playing, or in the Songs list (Windows). Smart playlists can use ratings.
- **Duplicate finder** (Browse → Duplicates). It only hides copies; it never deletes files.
- **Download lyrics from LRCLIB** (Settings → Online; off by default, no account).
- **Windows:** previous / play-pause / next buttons under the taskbar thumbnail.
- **Android:** a home-screen widget, and a lock-screen disc view (shown only if Gleo was in front when the phone locked; Settings → Lock screen turns it off).

## Windows improvements

- The rail shows labels when the window is wide, and Sound and Settings stay reachable in a small window.
- One click on the play button plays a song; a filter on the Songs page (Ctrl+F).
- Shorter album and artist headers, so the first songs stay in view; rows stop at 1,200 px in a big window.
- Clear queue has Undo; the queue has a history and a menu.
- Clearer toasts and error messages, an Add to playlist dialog where you can type a new name, settings drawn as proper choices, a tidier About and Credits, and many smaller fixes from the 0.4 design review.

## Phone improvements

- Five tabs: **Home · Songs · Albums · Artists · Library** (Library holds Playlists, Favourites, Folders and Browse). Settings is the gear at the top.
- Song rows show the artist and album; menus open as bottom sheets; buttons are finger-sized.
- Fast scrolling with the letter you are at, Shuffle on the Songs page, and a Sort chip.
- Now Playing is readable on bright covers, with lyrics, sleep and queue in thumb reach, and stars under the artist.
- Back works inside folders; search opens full screen; the system bars follow the light theme.
- Permissions recover after "Don't allow" (Gleo offers to open Settings), and the folder picker opens at Music.
- The screen stays on while Disc mode or the lock-screen view is open and music plays.

## Fixes

- Android 8 to 12: the notification and lock screen show previous / pause / next again.
- Android 13 and newer: `.lrc` lyrics are read again (add the folder with *Add folder* in Settings).
- Android: if a headphone button started Gleo in the background, opening it no longer hangs on the start screen.
- Search no longer shows a grey screen on the phone.
- Scrolling over the equalizer on the phone no longer changes it.
- "Gleo's pick" in Change cover is the same as *Reset to automatic*.

## Known limits

- Taskbar buttons were checked by test messages; please hover over Gleo in the taskbar to see them.
- CUE sheets embedded inside a FLAC file are not read yet; a separate `.cue` file is.
- A seek right after a song starts can be lost (an old bug).
- The GitHub links still use the old `lumen` repository names until the repositories are renamed (GitHub forwards the old links).
- The Android build is a **test build**, signed with the build computer's temporary key.
