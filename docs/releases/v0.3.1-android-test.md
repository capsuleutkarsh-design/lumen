# Lumen 0.3.1 beta for Android: test build

The second Android test build, in plain words. It installs over 0.3.0: your library, playlists and settings stay. Windows stays at 0.2.0 for now.

## New in 0.3.1

- **Sleep timer on the phone.** In Now Playing, tap the **moon**: 15, 30, 45 or 60 minutes, the end of this song, or the end of the queue. While it is on, the moon is lit and a line under the buttons says when the music pauses (for example *pauses at 11:30 PM*). The music fades out over the last 10 seconds. Tap the moon again and choose **Turn off** to cancel.
- **Music on an SD card, and any other folder.** *Settings → Library folders → Add folder* now opens Android's folder picker on the phone **and** on an SD card or USB stick. Choose a folder, tap **Use this folder**, then **Allow**. Lumen only reads it.
- **Export works on the phone.** *Export as M3U8* (long-press a playlist) and *Export my presets (JSON)* (Sound page → Preset) open Android's "Save to" screen: pick a place, for example Downloads, and tap **Save**. *Import M3U* and *Import presets (JSON)* read them back.
- **`folder.jpg` / `cover.jpg` covers on Android 13 and newer.** Lumen now also asks for **photos**, only to read the cover pictures next to your songs. If you say no, everything else still works: embedded covers and the art packs.

## How to install it on your OnePlus 6

1. On the phone, open this release page and download **`Lumen-0.3.1-beta-android-arm64-v8a.apk`**. (The other two files are for old 32-bit phones and for emulators.)
2. Open the downloaded file and tap **Install** (or **Update**). There is no need to uninstall 0.3.0 first.
3. Open **Lumen**.

New to Lumen? Tap **Allow access**, then **Allow**. Your **Music** folder is read at once; add more folders in *Settings*.

## Tip: Bluetooth sound

Apps can't choose the Bluetooth codec on Android 11; the phone does. If your phone and headphones support a better codec, you can pick it in *Settings → System → Developer options → Bluetooth audio codec*. Bluetooth is always lossy; a wired or USB headphone is the clean way.

## Known limits

- Android's folder picker does not allow the top of a storage or the **Download** folder itself: choose a folder inside them (for example *Music* or *Download/Albums*).
- On Android 13 and newer, if you already gave Lumen access with 0.3.0, it does not ask for photos again. To get `folder.jpg` covers there, allow **Photos** in *Settings → Apps → Lumen → Permissions*. (Your OnePlus 6 on Android 11 shows them already.)
- Files copied by a computer or a file manager appear at once. Files put on the phone some other way (for example by `adb`) only appear after the phone has indexed them.
- No output picker, exclusive mode or bit-perfect USB on Android yet. Android always mixes the sound.
- Calls pausing the music could not be tried on the emulator; please try a call on your phone.

## This is a TEST build

It is signed with the same **temporary key** as 0.3.0 (the debug key of the build computer), so it updates 0.3.0 in place. When the first properly signed Lumen comes, **uninstall the test build first**, then install the new one. Your play counts, playlists and settings in the test build go with the uninstall.
